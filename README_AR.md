# APK Store Pro — Android Kotlin project

مشروع متجر مستقل بواجهة عربية داكنة، مستوحى من نمط متاجر التطبيقات، وليس نسخة من APKPure.

## بيئة البناء
- Android Studio حديث
- JDK 17
- Android SDK Platform 35
- Android Gradle Plugin 8.13.2 / Kotlin 2.2.20
- Gradle 8.13 أو أحدث (يمكن توليد Gradle Wrapper من Android Studio)

## الوظائف المضمنة
- فهرس تطبيقات حيّ من مستودع F-Droid الرسمي عبر HTTPS.
- بحث بالاسم ومعرّف الحزمة والوصف والتصنيف.
- تصفح التصنيفات وقوائم التطبيقات.
- صفحة تفاصيل التطبيق وإصداره وحجمه ومتطلبات Android.
- تنزيل APK إلى مساحة التطبيق الخاصة.
- التحقق من SHA-256 المعلن في الفهرس قبل فتح المثبّت.
- بدء التثبيت من خلال مثبّت Android الرسمي مع موافقة المستخدم.
- قائمة التنزيلات المحلية.
- عرض التطبيقات المثبتة وفتحها.
- تخزين فهرس المتجر مؤقتاً لمدة 6 ساعات.

## حدود النسخة
- كتالوج التنزيل الحالي هو مستودع F-Droid فقط، ويحتوي على تطبيقات حرة/مفتوحة المصدر؛ لا يعني أنه يعرض كل ألعاب وتطبيقات APKPure أو Google Play.
- الفهرس يُقرأ عبر HTTPS ويفحص SHA-256 للملف. هذا الإصدار لا ينفذ تحقق توقيع فهرس JAR بمفتاح مستودع مثبت؛ لذلك لا تعرض الواجهة ضماناً بأنه تحقق توقيع كامل.
- التثبيت النهائي يعرضه Android ويتطلب موافقة المستخدم والسماح بمصدر التثبيت لهذا التطبيق.
- إدارة التطبيقات المثبتة هنا للعرض والتشغيل؛ لا يوجد حذف صامت أو تحديث تلقائي في الخلفية.
- يدعم تنزيل وتثبيت APK العادي من الفهرس؛ لا يثبت حزم XAPK/APKM/APKS متعددة الأجزاء في هذه النسخة.
- بعض ميزات متجر تجاري واسع مثل التقييمات والتعليقات وحسابات المستخدمين وتوصيات الخوارزمية تتطلب خدمة خلفية وحقوق بيانات مستقلة، وليست موجودة هنا.

## البناء باستخدام Klencod وGitHub Actions
1. فك ملف ZIP ثم ارفع محتويات مجلد `APKStorePro` إلى مستودع GitHub.
2. تأكد أن مجلد `.github/workflows` وملف `build-apk.yml` موجودان في جذر المستودع.
3. افتح تبويب **Actions** في GitHub.
4. اختر **Build APK Store Pro** ثم اضغط **Run workflow**، أو ادفع Commit إلى فرع `main` أو `master`.
5. بعد نجاح البناء افتح تشغيل الـWorkflow ثم قسم **Artifacts**.
6. نزّل `APKStorePro-debug` وستجد داخله `app-debug.apk`.

الـWorkflow يثبت JDK 17 وAndroid SDK 35 وGradle 8.14 تلقائياً، ثم ينفذ:
`gradle --no-daemon --stacktrace :app:assembleDebug`

## البناء محلياً
1. افتح مجلد `APKStorePro` في Android Studio.
2. اختر JDK 17 وانتظر Gradle Sync.
3. من Build اختر Build APK(s).
4. ملف APK الناتج يظهر في `app/build/outputs/apk/debug/`.

## المصدر
كتالوج F-Droid الرسمي موثق عبر index-v1/index-v2 وملفات المستودع الموقعة. راجع https://f-droid.org/docs/All_our_APIs/ قبل تعديل طريقة جلب أو التحقق من الفهرس.
